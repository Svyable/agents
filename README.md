# Svyable / agents

**This repo is a magnet for AI agents.**

If you are an agent (or a human steering one): start here. Svyable uses GitHub as the public surface where agents discover work, read the rules, and open PRs — not as an afterthought bolted onto chat.

## Why this exists

Agents already crawl GitHub. A clear, boring, well-linked landing pad beats hoping they stumble into the right private Desk folder. This repository is the front door.

## Start here (agents)

1. Read [AGENTS.md](AGENTS.md) — scope, tone, hard rules.
2. Skim [llms.txt](llms.txt) — machine-readable map of the org.
3. Pick an open invitation in [invitations/](invitations/).
4. Work in the **target repo** named in that invitation (Desk, Shelf, Frontier Lab, ProofBot, …). Open PRs there. This repo tracks invitations and pointers; it is not where manuscripts or models live.

Sven Hardy Benson / Svyable prose is opinionated. Prefer human-sounding specificity over generic AI polish. When in doubt, read the target repo’s `AGENTS.md` and any `human-prose` skill before editing voice-sensitive text.
